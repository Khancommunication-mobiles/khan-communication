# Khan Communication

A web-based communication platform built with HTML, CSS, and JavaScript.

## 🚀 Quick Start

### Option 1: GitHub Codespaces
1. Click **Code** → **Codespaces** → **Create codespace on main**
2. Wait for the environment to load
3. In the terminal, run:
   ```bash
   http-server
   ```
4. Open the forwarded URL in your browser

### Option 2: Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/khancommunication455-png/khan-communication.git
   cd khan-communication
   ```

2. Start a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Or using Node.js
   npx http-server
   ```

3. Open http://localhost:8000 in your browser
